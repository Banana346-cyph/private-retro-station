🚀 Startup

Control what happens when you start a game.

Skip Boot Animation Go directly to the emulator instead of showing the cartridge and TV sequence.
Auto Fullscreen Attempts to enter fullscreen when the emulator starts.
Remember Last Game Remembers the name of your last selected ROM on this device.

🕹️ Gameplay

Customize helpful information shown while playing.

Show Controller Tips Shows a small reminder that keyboard/controller controls are handled by EmulatorJS.
Keep Game Name Visible Shows the current ROM name near the top of the screen while playing.

🖥️ Interface

Change how Private Retro Station's own interface behaves.

Show Exit to Station Shows the custom button used to return to the launcher.
Focus Mode Makes the playing screen less distracting while keeping the exit button available.
Compact Launcher Reduces spacing on the launcher so more content fits on smaller screens.

v1.3.1

what changed, what got fixed, and what i’ve been messing with lately.

v1.3.1 · full prs refreshseptember 24, 2026
  • carried the new prs look into settings, changelog, reporting, admin, and crash recovery.
  • lowercased more of the interface and removed more of the glossy dashboard styling.
  • kept all of the existing tools and functionality underneath the new look.
v1.3.0 · prs rebrandseptember 24, 2026
  • Rebranded the launcher around the shorter PRS name.
  • New slogan: “pick a game. press play.”
  • Simplified the public launcher with flatter styling and fewer panels.
  • Kept emulator, settings, reporting, analytics, crash recovery, and admin tools intact.
v1.2.0 · recovery updateseptember 22, 2026
  • Added a dedicated emulator crash/recovery screen instead of leaving a blank or black screen.
  • Added automatic recovery logging to the owner admin dashboard.
  • Added Try Again, Return to Station, and Copy Error Details tools.
  • Upgraded the admin crash test so it destroys the active EmulatorJS session and verifies that Retry can rebuild the emulator and relaunch the selected ROM.
  • Added this version-aware What's New / changelog panel.
v1.1.3 · game finder updateseptember 22, 2026
  • Made the legal GBA homebrew game finder one of the first things visible in the launcher.
v1.1.1 · admin + analyticsseptember 21, 2026
  • Added the upgraded owner dashboard, diagnostics, local error history, and site statistics.
  • Connected Cloudflare Web Analytics for global traffic information.
